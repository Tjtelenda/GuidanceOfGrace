# Local knowledge generation

The portable bundled catalog contains 207 boss encounters, including 42 DLC encounters. It is an encounter catalog, not an exhaustive item database.

This PC also has a separately versioned generated catalog under `%APPDATA%\Guidance of Grace\knowledge\imported-markers.json`. It contains **14,481 records**:

Spell pickups are also present under the pickup categories (17 sorceries and 17 incantations). FMG table names are the game's internal table categories, not a count of unique usable spells or weapons. The index preserves source IDs and variants instead of silently deduplicating names.

## Provenance and scope

- Source: locally installed archives, executable file version `2.7.1.0`, read on 2026-09-15. This is file-version metadata, not an assertion that the public game patch has that version number.
- Local tool: `egormagurin/EldenRingMap@48f42e570ada1dd28717d7ce56aaeb92ee14521b`.
- Import schema: 1. Each catalog records source, game version and generation timestamp.
- Inputs were opened read-only. Extraction cache, generated JSON and maps were written outside the game directory.
- No memory-reading, live-memory server, wiki-scraping setup script, injection or game patching was used.
- Three local map layers were extracted with zero failed tiles, then resized for local companion use. Only a requested target's crop is shown by the app.

The extractor visited 1,248 map files. Its log reported 133 missing item-lot IDs, 37 out-of-range part references, 56 nameless lots, and three unplaceable records in `m10_01`. These are explicit coverage limitations. The 3,347 positions must not be represented as proof that every enemy drop, merchant stock entry, conditional reward or pickup is geographically resolved. Nearest-grace labels are geographic clues, not guaranteed travel routes. Curated Forge Supply records provide precise upgrade-bearing destinations independently.

## Updating on this PC

The app's **Generate from installed game** action runs the configured, hashed local extraction scripts, then validates and atomically imports the resulting JSON. The runner rejects changed entry scripts. `local-generation.json` points to the retained private tooling in this workspace and the bundled Python runtime. Keep those directories if using regeneration; the installed app can search its existing cache without them. Map images remain the initial local snapshot and are not regenerated by the item-catalog refresh.

The extractor is deliberately not redistributed without a clear license. Other machines can use **Import game-data index** with this format:

```json
{
  "schemaVersion": 1,
  "source": "generator name and revision",
  "gameVersion": "input game version",
  "generatedAt": "2026-09-15T00:00:00Z",
  "records": [{"id":"unique-id", "title":"Item name", "type":"pickup", "region":"Region", "location":"Place", "description":"Clue", "tags":[], "rewards":[], "eventId":12345}]
}
```

Optional local map coordinates use `layer` M00/M01/M10 and `x`,`y` in the extractor's 10,496-pixel master coordinate space. Unknown event-flag blocks stay unconfirmed and do not abort character parsing. Show All is required for undiscovered generated records; completed pickup/grace flags can unlock their corresponding records normally.

The network **Update Knowledge** action is separate: it checks only the configured trusted encounter source, validates identity/schema/counts/checksum, keeps a previous valid cache and falls back to bundled data offline. It never treats the player's save as knowledge data.
